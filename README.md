# Asthma trigger log

A diary for rescue-inhaler use that stamps each puff with when, where, and what the outdoor conditions were, then learns which conditions show up more on your inhaler days.

| Folder | What |
|--------|------|
| [`ios/`](ios/) | iOS app (SwiftUI, iOS 27, on-device AI). Main line of work. |
| [`web/`](web/) | Next.js prototype on Vercel + Supabase. See [`web/README.md`](web/README.md) to run or deploy it. |
| [`docs/`](docs/) | Design docs, the product spec. |
| [`fixtures/`](fixtures/) | Shared test data both apps must agree on. |

Agents and contributors: start with [AGENTS.md](AGENTS.md).

Not medical advice.
