# Bundled typefaces

All OFL. Registered in `ios/project.yml` via `UIAppFonts` (filenames only; Xcode copies them to the bundle root).

| Files | Use |
|-------|-----|
| `Recursive.ttf` + `Recursive-OFL.txt` | Default sentence voice (Settings › Insight voice axes) |
| `FunnelSans-*.ttf` + `FunnelSans-OFL.txt` | Opt-in via Settings › Type › Funnel Sans |

Funnel Sans source: [Dicotype/Funnel](https://github.com/Dicotype/Funnel) / [Google Fonts](https://fonts.google.com/specimen/Funnel+Sans). Weights shipped: Regular, Medium, SemiBold, Bold.
